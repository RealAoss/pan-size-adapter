# Pan Size Adapter

Scale a round cake recipe to the same batter depth in a new round pan.

Open `index.html` in a modern browser. Edit the sample inputs to update the result, then print or download it. Processing stays in the tab.

## Example

Original diameter (cm) = 20, New diameter (cm) = 24, Original batter mass (g) = 500. The first result is 1.44.
